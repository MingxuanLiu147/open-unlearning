# Agent 工具目录说明

本仓库中可能出现 `.claude/`、`.codex/`、`.cursor/`、`.gemini/` 等目录。它们用于不同 agent 或 IDE 工具保存提示词、技能、命令、会话辅助配置，不属于模型训练、评估、数据处理或算法运行时依赖。

本轮 Know-Surgery 收敛不修改这些目录的配置，也不删除其中内容。后续如果需要统一 agent 工具配置，应单独开一个清理任务，先确认保留范围、迁移方式和对使用者工作流的影响。

权威项目说明仍以根目录 `README.md`、`CLAUDE.md` 和 `docs/` 下的文档为准；agent 工具目录只作为开发辅助配置存在。
