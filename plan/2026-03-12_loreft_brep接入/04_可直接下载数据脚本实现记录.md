- `/home/liumingxuan/open-unlearning/scripts/prepare_brep_public_data.py`

## 脚本职责

### `prepare_brep_public_data.py`
- 下载并规范化直接可获取的 BREP 数据。
- 默认目标目录：
  - `/home/liumingxuan/open-unlearning/data/inject/brep/`
- 默认 raw 缓存目录：
  - `/home/liumingxuan/open-unlearning/data/inject/brep/_raw/`
- 自动生成：
  - 训练数据 JSON
  - 评测数据 JSON
  - 分析数据 JSONL
  - `manifest.json`

### `prepare_brep_public_data.sh`
- 作为 shell 包装入口，默认调用以下数据集：
  - `prm800k`
  - `ultrafeedback`
  - `gsm8k`
  - `hellaswag`
  - `svamp`
  - `mathqa`
  - `math500`
  - `amc23`
  - `truthfulqa`

## 明确排除的数据
- `math10k`
- `commonsense`

排除原因：
- 两者都不是单一可直接下载文件。
- 都需要按上游 recipe 重建，不能放进“直接下载”脚本里，否则会把来源、license 和字段映射混在一起。

## 主要实现点
- `prm800k`
  - 使用 OpenAI 官方仓库 raw URL 下载 `phase2_train.jsonl`
  - 参考 BREP 的 `deal_data.py` 转成 `instruction/output/answer`
- `ultrafeedback`
  - 从 HF 下载后，自动从候选 completions 中选择一个可用输出
- `gsm8k`
  - 保留完整 `answer` 到 `output`
  - 从 `####` 后提取最终答案到 `answer`
- `hellaswag`
  - 使用带标签 split
  - 把正确 ending 作为 `output` 和 `answer`
- `svamp`
  - 统一拼接题干和问题
- `mathqa`
  - 解析多选项文本
  - 用正确选项文本作为 `answer`
- `math500`
  - 直接保留 `problem/solution/answer`
- `amc23`
  - 带 dataset id fallback
- `truthfulqa`
  - 输出为 JSONL
  - 至少保留 `question/correct_answers/incorrect_answers`

## 运行方式

列出脚本支持的数据集：
```bash
cd /home/liumingxuan/open-unlearning
.venv/bin/python scripts/prepare_brep_public_data.py --list-datasets
```

准备默认的全部直接下载数据：
```bash
cd /home/liumingxuan/open-unlearning
bash scripts/prepare_brep_public_data.sh
```

做小规模 smoke 准备：
```bash
cd /home/liumingxuan/open-unlearning
.venv/bin/python scripts/prepare_brep_public_data.py --max-rows 10
```
