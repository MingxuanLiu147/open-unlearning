# 命令记录

## 一、真实 smoke test 使用的资源

本轮为了避免依赖外网下载，临时创建了：

- 本地 tiny 模型目录：`/tmp/inject_smoke_model`
- 本地 Alpaca 数据：`/tmp/inject_smoke_alpaca.json`

说明：

- smoke test 强制在 CPU 上执行：
  - `CUDA_VISIBLE_DEVICES=''`
- 每个算法仅跑 1 step：
  - `+trainer.args.max_steps=1`

## 二、真实 smoke test 命令

### 1. LoRA

```bash
cd /home/liumingxuan/open-unlearning

CUDA_VISIBLE_DEVICES='' HYDRA_FULL_ERROR=1 .venv/bin/python src/train.py \
  --config-name=inject.yaml \
  model=Llama-3.2-1B-Instruct \
  trainer=inject/LoRA \
  data/datasets@data.train=Custom_inject \
  data.train.train.Custom_train.args.data_path=/tmp/inject_smoke_alpaca.json \
  data.train.train.Custom_train.args.format_type=alpaca \
  model.model_args.pretrained_model_name_or_path=/tmp/inject_smoke_model \
  model.tokenizer_args.pretrained_model_name_or_path=/tmp/inject_smoke_model \
  model.model_args.attn_implementation=eager \
  model.model_args.torch_dtype=float32 \
  trainer.args.bf16=false \
  trainer.args.do_eval=false \
  trainer.args.per_device_train_batch_size=1 \
  trainer.args.gradient_accumulation_steps=1 \
  trainer.args.num_train_epochs=1 \
  +trainer.args.max_steps=1 \
  trainer.args.logging_steps=1 \
  trainer.args.output_dir=/tmp/inject_smoke_lora \
  task_name=inject_smoke_lora
```
