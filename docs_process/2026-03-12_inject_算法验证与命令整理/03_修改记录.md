# 修改记录

## 本轮实际修改的核心文件

### 1. Inject 数据集层

- `src/data/inject.py`
  - 增加 Alpaca / ShareGPT 样本的必需字段校验。
  - 当 `template_args.apply_chat_template=true` 且 tokenizer 支持时，改为走 chat template。
  - 去掉 dataset 级别 `padding="max_length"`，改为只截断，由 collator 动态 padding。

### 2. Inject 训练基础配置

- `configs/trainer/inject/base_inject.yaml`
  - `output_dir` 改为 `${paths.output_dir}`，让输出目录和 `task_name` 对齐。
  - `evaluation_strategy` 改为当前 `transformers` 兼容的 `eval_strategy`。
  - 默认 `eval_strategy` 改为字符串 `'no'`，避免没有 `eval_dataset` 时初始化失败。

### 3. Inject Trainer 兼容性修复

- `src/trainer/inject/base.py`
  - `compute_loss()` 兼容新版 `Trainer` 的额外 kwargs。

- `src/trainer/inject/lora.py`
  - `compute_loss()` 兼容新版 `Trainer`。
  - `target_modules` 从 Hydra `ListConfig` 转为普通 Python `list`，避免保存 adapter 时 JSON 序列化报错。

- `src/trainer/inject/dora.py`
  - `compute_loss()` 兼容新版 `Trainer`。
  - `target_modules` 转为普通 Python `list`。

- `src/trainer/inject/adalora.py`
  - `compute_loss()` 兼容新版 `Trainer`。
  - `target_modules` 转为普通 Python `list`。
  - 新增 `total_step` 推导逻辑，以兼容当前 `peft.AdaLoraConfig`。
  - 修复正交正则路径对当前 PEFT 参数容器结构的兼容性。

### 4. Experiment 配置补齐

- 新增：
  - `configs/experiment/inject/alpaca/adalora.yaml`

### 5. 共享注释澄清

- `src/data/__init__.py`
- `src/train.py`
- `configs/inject.yaml`
