# 执行总表：Llama-3.2-1B 遗忘方法批量运行

## 本轮执行原则
- 目标模型：`Llama-3.2-1B-Instruct`
- 基础权重：`open-unlearning/tofu_Llama-3.2-1B-Instruct_full`
- 训练 tokenizer：`saves/unlearn/my_npo_debug`
- 数据配置：默认使用 `forget10 / retain90 / holdout10`
- 运行方式：单卡顺序执行
- 首选 GPU：`CUDA_VISIBLE_DEVICES=2`
- 稳定性优先覆盖：
  - `model.model_args.attn_implementation=eager`
  - `trainer.args.per_device_train_batch_size=1`
  - `trainer.args.per_device_eval_batch_size=1`
  - `trainer.args.gradient_accumulation_steps=4`
  - `trainer.args.eval_strategy=no`
  - `trainer.args.eval_on_start=false`
  - `trainer.args.do_eval=false`
  - `trainer.args.save_strategy=no`
  - `trainer.args.logging_steps=10`

## 本轮纳入的方法
- `GradAscent`
- `GradDiff`
- `NPO`
- `SimNPO`
- `DPO`
- `RMU`
- `UNDIAL`
- `CEU`
- `SatImp`
- `WGA`
- `PDU`

## 特殊方法说明
- `DPO` 使用 `experiment=unlearn/tofu/idk`
- `PDU` 显式覆盖：
  - `trainer.method_args.retain_loss_eps=0.3`
  - `trainer.method_args.alpha=100`
  - `trainer.method_args.primal_dual=true`
  - `trainer.method_args.dual_step_size=5`
  - `trainer.method_args.dual_warmup_epochs=5`

## 统一输出约定
- 训练输出：`saves/unlearn/<task_name>/`
- 评测输出：`saves/unlearn/<task_name>/evals/`
- 运行日志：本目录下 `run_all_methods.log`
- 每个方法的最终配置与命令将在运行完成后整理到 `../配置文档/`

## 已确认的环境约束
- 直接访问 `meta-llama/Llama-3.2-1B-Instruct` tokenizer 会触发 Hugging Face gated repo 403。
- 因此训练阶段统一改为加载本地已保存 tokenizer，避免访问 gated repo。
