## 评测阶段问题与修复
- `flash_attention_2` 在当前环境下存在 ABI 不兼容，直接导致评测加载模型时报错。
- 评测阶段统一修复方式：
  - 显式传入 `model.model_args.attn_implementation=eager`
- 多个 TOFU 评测并发共享默认 Hugging Face datasets cache 时，会互相清理 `locuslab/TOFU` 的缓存目录，导致 summary 只写出前半段指标。
- 对 `DPO / NPO / PDU` 的最终补评测，统一改为：
  - 独立 `HF_HOME`
  - 独立 `HF_DATASETS_CACHE`
  - 单方法单 GPU
- 已归档的首次不完整评测目录：
  - `saves/unlearn/20260324_r3_tofu_Llama-3.2-1B-Instruct_forget10_DPO/evals_incomplete_20260324T174813Z`
  - `saves/unlearn/20260324_r3_tofu_Llama-3.2-1B-Instruct_forget10_NPO/evals_incomplete_20260324T174813Z`
