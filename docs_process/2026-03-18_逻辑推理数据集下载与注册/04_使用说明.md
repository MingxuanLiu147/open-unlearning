# 使用说明

## 重新准备数据

```bash
cd /home/liumingxuan/open-unlearning
PYTHONPATH=src .venv/bin/python scripts/prepare_logic_reasoning_public_data.py
```

只准备某个数据集时可用：

```bash
PYTHONPATH=src .venv/bin/python scripts/prepare_logic_reasoning_public_data.py --datasets proofwriter
```

## 可用配置名

- 训练：
  - `CLUTRR_train_inject`
  - `RuleTaker_train_inject`
  - `ProofWriter_train_inject`
  - `FOLIO_train_inject`
  - `LogicBench_train_inject`
- 评测：
  - `CLUTRR_eval_inject`
  - `RuleTaker_eval_inject`
  - `ProofWriter_eval_inject`
  - `FOLIO_eval_inject`
  - `LogicBench_eval_inject`
  - `RuleArena_eval_inject`

## Hydra 使用示例

训练：

```bash
python src/train.py --config-name=inject.yaml data/datasets@data.train=ProofWriter_train_inject
```

评测：

```bash
python src/eval.py --config-name=inject.yaml data/datasets@data.eval=RuleArena_eval_inject
```
